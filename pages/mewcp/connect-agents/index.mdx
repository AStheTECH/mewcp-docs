Every AI app connects to MewCP the same way: one URL and one key. Once it is set up, the app can use every app you have connected in MewCP, and connecting another one later needs no change in the AI app.

## What you need

- **A API Key.** In the [dashboard](https://mewcp.com/dashboard), go to **API Keys** and copy your key. It starts with `mcp_live_`. See [API Key](/mewcp/authentication/mewcp-key).
- **At least one app connected.** In the dashboard, go to **Servers**, pick an app and connect your account. You can connect more at any time.

Every guide uses the same two values:

| Value  | What to use                              |
| ------ | ---------------------------------------- |
| URL    | `https://gateway.mewcp.com/personal/mcp` |
| Header | `Authorization: Bearer API_KEY`          |

The URL is your **personal toolset**: the apps you have connected. MewCP signs in with your key for now. If your AI app asks for a sign-in method, choose the option for an API key or custom header, not OAuth.

Any AI app that can reach a remote MCP server over streamable HTTP and send a custom header can connect, even if it is not listed above.

## What your agent sees

Your AI app will not list the tools of every app you have connected. It sees four:

| Tool            | What it does                                     |
| --------------- | ------------------------------------------------ |
| `search`        | Find tools by keyword across every connected app |
| `get_schema`    | Get the parameters for the tools it picked       |
| `list_accounts` | List the accounts connected for one app          |
| `call_tool`     | Run the tool                                     |

That is expected. The agent uses them to find and run the right tool for whatever you ask, so you keep asking in plain language. Keeping the list to four is what keeps it accurate as you connect more apps. See [How MewCP works](/mewcp/getting-started#how-mewcp-works) for more.
